# ربات آرشیو دانشکده ریاضی

ربات تلگرامی برای دسترسی به ویدیوها، جزوات و نمونه سوالات دروس دانشکده ریاضی.

## ویژگی‌ها

- لیست دروس با منوی سه‌تایی: ویدیو / جزوات و کتاب‌ها / نمونه سوالات و امتحانات
- ویدیو: تماشا در نماشا، دانلود مستقیم، ارسال فایل در ربات (اختیاری)
- جزوات و نمونه سوالات: PDF یا عکس (یکی یا چندتا) همراه کپشن
- جستجو، آخرین ویدیوها، پنل ادمین کامل
- دیتابیس **PostgreSQL** (روی Railway داده‌ها با Deploy پاک نمی‌شوند)

## ساختار پروژه

```
maths_archive_bot/
├── bot.py              # کد اصلی ربات
├── requirements.txt    # وابستگی‌ها
├── .env.example        # نمونه تنظیمات
├── .gitignore
└── README.md
```

## متغیرهای محیطی

فایل `.env` را از روی `.env.example` بسازید:

```bash
cp .env.example .env
```

| متغیر | توضیح | مثال |
|--------|--------|------|
| `BOT_TOKEN` | توکن ربات از @BotFather | `123456:ABC...` |
| `ADMIN_IDS` | آیدی عددی ادمین(ها)، با کاما | `1612559025` |
| `DATABASE_URL` | آدرس PostgreSQL | `postgresql://...` |

بدون `DATABASE_URL` ربات اجرا نمی‌شود.

## دیتابیس PostgreSQL

این ربات به SQLite وابسته **نیست** و فقط PostgreSQL را پشتیبانی می‌کند.

- روی **Railway**: سرویس Postgres اضافه کنید و `DATABASE_URL` را به سرویس ربات وصل کنید.
- گزینه‌های دیگر: [Supabase](https://supabase.com)، [Neon](https://neon.tech)

## نصب و اجرا (لوکال)

```bash
git clone <repo-url>
cd maths_archive_bot
python -m venv venv
# ویندوز: venv\Scripts\activate
# لینوکس/مک: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# مقادیر .env را پر کنید
python bot.py
```

## استفاده به‌عنوان ادمین

1. `/start` و سپس **⚙️ پنل مدیریت**
2. **➕ افزودن درس** — نام درس
3. **🎬 افزودن ویدیو** — درس → عنوان → لینک نماشا → لینک دانلود (یا «ندارد») → فایل تلگرام (یا «رد»)
4. **📎 افزودن جزوه/سوال** — درس → نوع (جزوه / نمونه سوال) → دسته → عنوان → ارسال PDF یا عکس (چند فایل) → «تمام»
5. ویرایش / حذف درس، ویدیو و جزوه/سوال از همان پنل

برای لغو هر عملیات: `/cancel` یا **🏠 منوی اصلی**

## دیپلوی (Railway)

1. ریپو را به Railway وصل کنید
2. سرویس PostgreSQL اضافه و `DATABASE_URL` را Reference کنید
3. `BOT_TOKEN` و `ADMIN_IDS` را در Variables بگذارید
4. Deploy

## نکات مهم

- فایل `.env` را هرگز در گیت کامیت نکنید.
- برای ادمین جدید، آیدی عددی را به `ADMIN_IDS` اضافه کنید.
- فایل‌های جزوه/ویدیو به‌صورت `file_id` تلگرام ذخیره می‌شوند و روی دیسک سرور کپی نمی‌شوند.
