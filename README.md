# ربات آرشیو دانشکده ریاضی (Maths Archive Bot)

ربات تلگرامی برای دسترسی دانشجویان به:

- ویدیوهای دروس (لینک نماشا + لینک دانلود + پخش مستقیم از تلگرام)
- جزوات و کتاب‌ها (PDF / عکس)
- نمونه سوالات (PDF / عکس)

این راهنما طوری نوشته شده که **حتی اگر هیچ دانش برنامه‌نویسی نداشته باشید** بتوانید ربات را راه بیندازید، داده وارد کنید و روی اینترنت همیشه روشن نگه دارید.

## 1. ربات چه کار می‌کند؟

```
دانشجو → ربات تلگرام → انتخاب درس → ویدیو / جزوه / نمونه سوال
                              ↑
                         PostgreSQL
                    (درس‌ها، لینک‌ها، file_id)
```

- **دانشجو:** لیست دروس، قسمت‌ها، لینک تماشا، لینک دانلود، و در صورت وجود پخش مستقیم ویدیو از تلگرام.
- **ادمین:** افزودن/ویرایش/حذف درس و ویدیو، آپلود جزوه و نمونه سوال، اتصال دسته‌ای فایل تلگرام با `/autolink`.

## 2. پیش‌نیازها

| مورد | توضیح ساده |
|------|------------|
| حساب تلگرام | برای ساخت ربات و تست |
| Python 3.12 | فقط اگر می‌خواهید روی لپ‌تاپ اجرا کنید |
| حساب GitHub | برای نگه داشتن کد و اتصال به Render/Railway |
| دیتابیس PostgreSQL | محل ذخیره درس‌ها و ویدیوها (مثلاً Supabase) |
| VPN (گاهی) | در ایران برای دسترسی به API تلگرام یا Render |

## 3. ساخت ربات در تلگرام

1. در تلگرام به **@BotFather** پیام بدهید.
2. دستور `/newbot` را بفرستید.
3. یک نام نمایشی و یک **یوزرنیم** که به `bot` ختم شود انتخاب کنید (مثلاً `MathsArchiveBot`).
4. BotFather یک **توکن** می‌دهد شبیه:
   ```text
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```
5. این توکن را محرمانه نگه دارید؛ هر کسی آن را داشته باشد می‌تواند ربات شما را کنترل کند.

**پیدا کردن آیدی عددی خودتان (برای ادمین شدن):**

1. به **@userinfobot** یا **@getidsbot** پیام بدهید.
2. عددی شبیه `1612559025` می‌گیرید → همان را در `ADMIN_IDS` بگذارید.

برای ادمین دوم، آیدی‌ها را با **کاما** جدا کنید:

```text
ADMIN_IDS=1612559025,987654321
```

## 4. متغیرهای محیطی (`.env`)

فایل `.env` کنار `bot.py` قرار می‌گیرد و **هرگز** نباید روی GitHub عمومی push شود (در `.gitignore` هست).

نمونه از `.env.example`:

```env
BOT_TOKEN=توکن_از_BotFather
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/postgres
ADMIN_IDS=1612559025
```

| متغیر | معنی |
|--------|------|
| `BOT_TOKEN` | توکن ربات |
| `DATABASE_URL` | آدرس کامل PostgreSQL |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها با کاما |

روی **Render / Railway** همین نام‌ها را در بخش Environment Variables تعریف می‌کنید؛ دیگر نیازی به فایل `.env` روی سرور نیست.

## 5. دیتابیس چیست و کدام را انتخاب کنیم؟

دیتابیس = جدول‌های ذخیره‌سازی درس‌ها و ویدیوها روی اینترنت.

ربات با **PostgreSQL** کار می‌کند (نه فایل Excel به‌صورت زنده).

### گزینه پیشنهادی: Supabase (رایگان مناسب شروع)

1. بروید به [https://supabase.com](https://supabase.com) و ثبت‌نام کنید.
2. **New project** بسازید (رمز قوی برای دیتابیس انتخاب کنید و آن را یادداشت کنید).
3. از منوی پروژه: **Project Settings → Database → Connection string → URI**.
4. رشته را کپی کنید. شبیه این است:
   ```text
   postgresql://postgres.xxxxx:PASSWORD@aws-0-....pooler.supabase.com:5432/postgres
   ```
5. اگر پسورد کاراکتر فارسی یا خاص دارد، باید **URL-encode** شده باشد.

**نکته:** حالت **Session / Transaction pooler** (پورت ۵۴۳۲) برای این ربات مناسب است.

### گزینه‌های دیگر

| سرویس | توضیح |
|--------|--------|
| **Neon** | PostgreSQL ابری رایگان؛ مشابه Supabase |
| **Railway Postgres** | دیتابیس کنار سرویس Railway؛ آسان ولی پلن رایگان محدود |
| **Postgres لوکال** | فقط برای تست روی لپ‌تاپ (`localhost`) |

ربات در اولین اجرا جدول‌ها را خودش می‌سازد (`courses`, `videos`, `materials`).

## 6. اجرای ربات روی لپ‌تاپ (لوکال)

مناسب تست. تا وقتی پنجره ترمینال باز است و اینترنت قطع نشود ربات جواب می‌دهد.

### ویندوز (PowerShell)

```powershell
cd C:\Users\pi\maths_archive_bot

python -m venv venv
.\venv\Scripts\activate

pip install -r requirements.txt

copy .env.example .env
notepad .env

python bot.py
```

اگر نوشت `PostgreSQL آماده است` و خطا نداد، در تلگرام به ربات `/start` بدهید.

**توقف:** در ترمینال `Ctrl+C`.

## 7. اجرای ربات روی Render

Render ربات را روی اینترنت نگه می‌دارد تا لپ‌تاپ شما خاموش باشد.

### مراحل

1. کد را روی **GitHub** پوش کنید.
2. در [https://render.com](https://render.com) ثبت‌نام کنید (می‌توانید با GitHub).
3. **New → Background Worker** (یا Web Service اگر health URL می‌خواهید).
4. ریپوی پروژه را وصل کنید.
5. تنظیمات تقریباً:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
6. در **Environment** اضافه کنید:
   - `BOT_TOKEN`
   - `DATABASE_URL` (از Supabase)
   - `ADMIN_IDS`
7. Deploy را بزنید و منتظر **Live** بمانید.

سپس در تلگرام `/start`.

### نکته پلن رایگان Render

- سرویس ممکن است بعد از بیکاری **بخوابد**.
- برای بیدار ماندن بخش ۹ را ببینید.
- فایل `runtime.txt` نسخه Python را مشخص می‌کند (مثلاً `python-3.12.8`).

## 8. اجرای ربات روی Railway

1. [https://railway.app](https://railway.app) → ورود با GitHub.
2. **New Project → Deploy from GitHub** → انتخاب ریپو.
3. اگر خواستید از Postgres خود Railway استفاده کنید: **Add → Database → PostgreSQL** و `DATABASE_URL` را به سرویس ربات وصل کنید.
4. در Variables همان `BOT_TOKEN` و `ADMIN_IDS` را بگذارید.
5. Start command: `python bot.py`.

پلن رایگان Railway محدودیت اعتبار ماهیانه دارد؛ بعد از اتمام، سرویس متوقف می‌شود مگر ارتقا دهید.

---

## 9. جلوگیری از خوابیدن ربات رایگان

روی Render رایگان، اگر مدتی کسی پیام ندهد سرویس می‌خوابد و اولین `/start` ممکن است دیر جواب دهد.

**راه‌حل رایج:** سرویس [UptimeRobot](https://uptimerobot.com) هر ۵ دقیقه یک درخواست HTTP به آدرس سرویس بزند.

1. ربات یک وب‌سرور خیلی سبک برای health check دارد.
2. اگر **Web Service** روی Render دارید، URL عمومی را در UptimeRobot به‌صورت مانیتور HTTP (GET یا HEAD) ثبت کنید.
3. اگر فقط Background Worker دارید و URL عمومی نیست، یا به Web Service سوییچ کنید یا روش keep-alive دیگری استفاده کنید.

## 10. پوشه `tools` و فایل‌های Excel

این بخش برای **پر کردن اولیه آرشیو** است، نه برای کار روزمره دانشجویان.

### فایل‌های داخل `tools/`

| فایل | کار |
|------|-----|
| `scrape_full_archive.py` | از کانال نماشا `mathsbu` همه ویدیوها را جمع می‌کند → Excel |
| `scrape_namasha_to_excel.py` | نسخه ساده‌تر / قدیمی‌تر اسکرپ |
| `import_excel_to_db.py` | Excel را به PostgreSQL وارد می‌کند |
| `reset_database.py` | همه درس‌ها و ویدیوها را **خالی** می‌کند (خطرناک) |
| `audit_archive.py` | گزارش پوشش `telegram_file_id` و آمار |
| `sync_channel_file_ids.py` | اتصال خودکار از کانال تلگرام با Telethon (اختیاری) |
| `requirements-tools.txt` | کتابخانه‌های اضافه برای اسکرپ و Excel |

### فایل‌های Excel

| فایل | معنی تقریبی |
|------|----------------|
| `namasha_mathsbu_complete.xlsx` | خروجی خام اسکرپ کامل (همه درس‌ها) |
| `namasha_mathsbu_clean_final.xlsx` | نسخه **تمیز**: نام درس یکدست، عنوان کوتاه مثل «قسمت ۲۵»، بدون تکراری |
| نسخه‌های `full_clean` / `deduped` | میانی قدیمی‌تر؛ اگر `clean_final` دارید همان کافی است |

**عنوان کوتاه در Excel تمیز:**

- قبل: `احتمال ۱ الهه مومنیان - قسمت 25`
- بعد: `قسمت 25`
- بخش‌ها: `20-4` → `قسمت 20 (بخش چهارم)`

نام درس در ستون `course_name` جدا است.

### گردش کار پیشنهادی از صفر

```text
۱) خالی کردن دیتابیس (فقط اگر از نو می‌خواهید)
   python tools/reset_database.py --yes

۲) اسکرپ از نماشا
   pip install -r tools/requirements-tools.txt
   python tools/scrape_full_archive.py
   → namasha_mathsbu_complete.xlsx

۳) استفاده از نسخه تمیز
   → namasha_mathsbu_clean_final.xlsx

۴) ورود به دیتابیس
   python tools/import_excel_to_db.py namasha_mathsbu_clean_final.xlsx

۵) در تلگرام: /autolink و فوروارد از کانال آرشیو
```

### import

```powershell
$env:DATABASE_URL="postgresql://..."
python tools\import_excel_to_db.py namasha_mathsbu_clean_final.xlsx
```

ردیف‌هایی با همان `namasha_url` تکراری ساخته نمی‌شوند.

## 11. دستورات ادمین داخل ربات

فقط آیدی‌های `ADMIN_IDS` پنل ادمین را می‌بینند.

| عمل | توضیح |
|-----|--------|
| `/start` | منوی اصلی |
| افزودن / ویرایش / حذف درس | مدیریت نام درس |
| افزودن / ویرایش / حذف ویدیو | عنوان، قسمت، لینک نماشا، دانلود، فایل تلگرام |
| جزوات و نمونه سوال | آپلود PDF یا عکس |
| `/autolink` | روشن کردن اتصال فوروارد |
| `/autolink_off` | خاموش کردن |
| `/cancel` یا منوی اصلی | خروج از مکالمه ناقص |

## 12. وصل کردن ویدیوهای تلگرام (`/autolink`)

1. ادمین: `/autolink`
2. ویدیوها را از کانال به چت ربات **فوروارد** کند (کپشن مهم است).
3. ربات:
   - اگر درس + قسمت هست → فقط فایل را وصل می‌کند.
   - اگر نیست (مثلاً فقط در تلگرام بود) → از کپشن می‌سازد و وصل می‌کند.
4. `/autolink_off`

نمونه کپشن خوب: `نظریه آمار ۱ دکتر روحانی - قسمت 1`

---

## 13. عیب‌یابی رایج

| مشکل | راه حل |
|------|--------|
| `Timed out` تلگرام | VPN سیستم |
| `DATABASE_URL` خالی | در `.env` یا Render پر کنید |
| `password authentication failed` | رمز یا URL-encode اشتباه |
| `getaddrinfo failed` | اینترنت/DNS یا VPN |
| ربات بعد از مدتی ساکت | خواب رایگان؛ keep-alive |
| autolink درس اشتباه | کپشن را چک کنید؛ file_id را پاک و دوباره فوروارد کنید |
| ویرایش ویدیو فوروارد را نمی‌گیرد | اول `/autolink_off` |
