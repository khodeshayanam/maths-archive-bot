# ربات آرشیو ویدیوهای دانشکده ریاضی

نسخه ساده — لینک به نماشا + دسته‌بندی و جستجو

## ویژگی‌ها

- لیست دروس
- مشاهده قسمت‌های هر درس
- جستجو
- آخرین ویدیوها
- پنل مدیریت برای ادمین (افزودن درس و ویدیو)

## نصب و اجرا (خیلی ساده)

### ۱. نصب پایتون
اگر پایتون ندارید از سایت python.org نسخه ۳.۱۰ یا بالاتر را نصب کنید.

### ۲. نصب کتابخانه‌ها
در پوشه پروژه این دستور را بزنید:

```bash
pip install -r requirements.txt
```

### ۳. تنظیم ادمین
فایل `.env` را باز کنید و جلوی `ADMIN_IDS=` آیدی عددی تلگرام خودتان را بنویسید.

چطور آیدی خود را پیدا کنید؟
- به ربات @userinfobot پیام دهید
- عددی که می‌دهد را کپی کنید و در فایل `.env` بگذارید

مثال:
```
ADMIN_IDS=123456789
```

اگر چند ادمین می‌خواهید:
```
ADMIN_IDS=123456789,987654321
```

### ۴. اجرای ربات

```bash
python bot.py
```

اگر پیام `🤖 ربات در حال اجرا است...` را دیدید، ربات آماده است.

### ۵. تست
در تلگرام ربات خود را پیدا کنید و `/start` بزنید.

## استفاده به عنوان ادمین

1. روی دکمه **⚙️ پنل مدیریت** بزنید
2. درس جدید اضافه کنید
3. ویدیو جدید اضافه کنید (لینک نماشا را بفرستید)
