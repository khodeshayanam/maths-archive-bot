# ربات آرشیو ویدیوهای دانشکده ریاضی

ربات تلگرامی ساده برای دسته‌بندی و دسترسی آسان به ویدیوهای آموزشی دانشکده ریاضی (لینک به نماشا).

## ویژگی‌ها

- لیست دروس با دسته‌بندی
- مشاهده قسمت‌های هر درس
- جستجو در عنوان درس و ویدیو
- آخرین ویدیوهای اضافه‌شده
- پنل مدیریت برای ادمین (افزودن / ویرایش / حذف درس و ویدیو)
- دیتابیس PostgreSQL (داده‌ها با Deploy پاک نمی‌شوند)
- پشتیبانی از چند ادمین

## ساختار پروژه

```
maths_archive_bot/
├── bot.py              # کد اصلی ربات
├── requirements.txt    # وابستگی‌ها
├── .env.example        # نمونه تنظیمات
├── .gitignore
└── README.md
```

## نصب و اجرا (لوکال)

### متغیرهای محیطی

فایل `.env` را از روی `.env.example` بسازید:

```bash
cp .env.example .env
```

مقادیر زیر را پر کنید:

| متغیر | توضیح |
|--------|--------|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `ADMIN_IDS` | آیدی عددی ادمین(ها)، با کاما جدا شود |
| `DATABASE_URL` | آدرس PostgreSQL |

### دیتابیس PostgreSQL

این ربات به SQLite وابسته نیست و به **PostgreSQL** نیاز دارد.

- روی **Railway**: یک سرویس Postgres اضافه کنید و `DATABASE_URL` را به سرویس ربات وصل کنید.
- سرویس‌های رایگان دیگر: [Supabase](https://supabase.com)، [Neon](https://neon.tech)

بدون `DATABASE_URL` ربات اجرا نمی‌شود.


1. کلون کردن پروژه:
```bash
git clone <repo-url>
cd maths_archive_bot
```

2. ساخت محیط مجازی (پیشنهادی):
```bash
python -m venv venv
# ویندوز:
venv\Scripts\activate
# لینوکس/مک:
source venv/bin/activate
```

3. نصب وابستگی‌ها:
```bash
pip install -r requirements.txt
```

4. تنظیم متغیرهای محیطی:
```bash
cp .env.example .env
```
سپس فایل `.env` را باز کنید و مقادیر را پر کنید:
- `BOT_TOKEN`: توکن دریافتی از @BotFather
- `ADMIN_IDS`: آیدی عددی تلگرام ادمین‌ها (با کاما جدا شوند)

5. اجرای ربات:
```bash
python bot.py
```

## متغیرهای محیطی

| متغیر       | توضیح                                      | مثال                          |
|-------------|--------------------------------------------|-------------------------------|
| BOT_TOKEN   | توکن ربات تلگرام                           | 123456:ABC...                 |
| ADMIN_IDS   | آیدی عددی ادمین‌ها (جدا شده با کاما)       | 1612559025,987654321          |

## استفاده به عنوان ادمین

1. ربات را استارت کنید (`/start`)
2. دکمه **⚙️ پنل مدیریت** را بزنید
3. درس جدید اضافه کنید
4. ویدیوهای مربوط به هر درس را با لینک نماشا اضافه کنید

## دیپلوی روی Railway / Render

برای اجرای دائمی ربات می‌توانید از سرویس‌های رایگان مثل Railway یا Render استفاده کنید.
راهنمای کامل دیپلوی در ادامه اضافه خواهد شد.

## نکات مهم

- فایل `.env` را هرگز در گیت کامیت نکنید.
- دیتابیس به صورت SQLite ساخته می‌شود و فایل `database.db` در همان پوشه ایجاد می‌گردد.
- برای اضافه کردن ادمین جدید، کافی است آیدی عددی او را به `ADMIN_IDS` اضافه کنید.
